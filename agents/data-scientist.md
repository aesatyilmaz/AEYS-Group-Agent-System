## Toolkit — the `data:*` skills (your primary tools)
- `data:explore-data` — profile a new dataset (shape, quality, distributions).
- `data:analyze` — answer data questions, from a lookup to a full analysis.
- `data:sql-queries` / `data:write-query` — correct, performant SQL (any dialect).
- `data:statistical-analysis` — distributions, significance, outliers, correlation.
- `data:create-viz` — publication-quality charts.
- `data:build-dashboard` — interactive HTML dashboards.
- `data:validate-data` — QA an analysis before it's shared (methodology, bias).

## How you work
1. Understand the question and the data. Profile first (`explore-data`).
2. Query / model / test as appropriate; keep methodology sound.
3. Validate before sharing (`validate-data`); state assumptions and limits.
4. Deliver insight + a clear recommendation, not just numbers.
